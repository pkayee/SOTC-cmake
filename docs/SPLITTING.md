# Splitting: adding C files, chunking modules

## How splat segments work here
Each module's `config/<MODULE>/<MODULE>.yaml` lists segments by file offset, e.g. `- [0x10d0, c, loaderSys, "-O3"]`. `asm` segments are assembled from `asm/<MODULE>/<name>.s`; `c` segments are compiled from `src/<MODULE>/<name>.c`, where each function still unmatched is an `INCLUDE_ASM("asm/<MODULE>/nonmatchings/<name>", fn);` line pulling in `asm/<MODULE>/nonmatchings/<name>/fn.s`. The option string after the name carries per-segment flags (`-O2 -G0`) and `cc=<compiler dir>`.

## Flip an `asm` segment to `c` (one yaml change, byte-neutral)
1. Edit the segment type `asm` -> `c` (keep the offset and name).
2. `rm config/<MODULE>/*_auto.txt && ./configure.py -c -t <alias>` (one target per process).
3. Create `src/<MODULE>/<name>.c` with `#include "common.h"` and one `INCLUDE_ASM(...)` per function in `asm/<MODULE>/nonmatchings/<name>/*.s`; add it with `git add -f` if git ignores it.
4. `make && for f in checksum-*.sha1; do sha1sum -c $f; done` must be 10 x OK while every function is still `INCLUDE_ASM`.
Splat deletes the per-function `.s` of a function that has a real C definition, so after you revert a function to `INCLUDE_ASM` (or `tools/unmatch`) re-run `./configure.py -c -t <alias>` for that module before building.

## Chunking a whole-module asm segment: `tools/chunk.py`
```sh
tools/chunk.py . <MODULE.XFF> [--target KB] [--min KB] [--max KB] [--dry]
```
Splits the single `[off, asm, all_text]` segment at 8-aligned real function starts (not splat's `func_` false starts, previous function ends in `jr/j/b` + delay slot) into `chunk/cNNNN_<first function>` C segments, reconfigures, builds and requires the module SHA1; on any failure it restores the yaml and says why. On this tree every module is already chunked, so it exits with ``no `[ off, asm, all_text ]` line (already chunked?)``.

## Rodata slices: `tools/slice_rodata.py`
```sh
tools/slice_rodata.py . <MODULE.XFF> [--dry]
```
After chunking, `.rodata` is still one blob, so C needing its own strings/float constants/jump tables cannot match. The script gives each chunk the slice its functions reference (compilers emit a TU's rodata contiguously and in function order; addresses referenced by 3 or more chunks are treated as shared; cuts rounded down to 8), reconfigures, builds and requires the SHA1. Slices land in `asm/<MODULE>/data/chunk/<chunk>.rodata.s`. Already applied to all modules here (`no [ off, rodata, all_rodata ] line`).

## Pitfalls
- **Alignment:** the last function of a C segment with size 4 mod 8 changes the next segment's alignment; keep it `INCLUDE_ASM` unless every checksum holds. Never pad with asm. The loader's `strtol`/`__sclose` alignment-pad gap closed once the following segment was C.
- **`ignore_symbols`:** a symbol splat wrongly emits goes into `config/<MODULE>/<MODULE>_ignore_symbols.txt`; re-run configure.
- **Generated lists:** `*_undefined_syms_auto.txt` / `*_undefined_funcs_auto.txt` are regenerated by every configure (delete before configuring a target); put hand-maintained externs into `undefined_syms.txt`.
- **Mixed compilers:** a segment that contains both SDK and game code needs a split at the boundary so each half gets its own `cc=`.
- **Configure per target.** Never a bare `./configure.py -c`.
